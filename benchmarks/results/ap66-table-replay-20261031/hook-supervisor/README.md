# Guarded commit-hook attempts

The two original normal-commit attempts were terminated by the original R6 supervisor when a short-lived child caused `ProcessLookupError` while reading `/proc`. A third attempt under the corrected supervisor stopped when a process identity changed while sampling; the guard did not relax that check. All three raw attempts are retained, and no commit was made by them.

`original-supervisor.py` is the original capsule guard. `prep_supervisor.py` is the approved private correction: two exception clauses recognize `ProcessLookupError` alongside `FileNotFoundError`. The outer clause still requires the captured pidfd to report exit; unreadable live processes fail closed. Admission, CPU, sampled tree-RSS, deadline and cleanup logic are unchanged. `test_guard.py` checks the dead and live pidfd cases, and `validation.stdout` records the two controls passing under the original guard. `prep_admission.py` is the unchanged original admission module. The source-diff and this evidence are not a separate code task.

The candidate was integrated without source conflicts over APP base `b85b44f12ec857fc0249bc956e239feadfe92ca4`. Seven peer files in the imported readset had changed since the earlier source pin, so the native caller, pure gate and harness consumer suite was rerun against the final integrated files: 112 passed, with process-tree sampled peak RSS 235,085,824 bytes (`integrated-validation.stdout`). `integrated-source-sha256.txt` binds the target and changed peer files.

The full canonical staged-diff hook passed on candidate `ff75cb8426b40b247ad6eb0b8fd758d32adf4599` (`canonical-commit-hook-r4.stdout`, child exit zero, sampled peak 84,094,976 bytes). Before push, APP main advanced to `3e6b7b2ec02eb30abbc0f6449cc61035032e8035`; its seeding-injection change touches the imported readset but does not conflict with this source. The same 112-test suite passed on the rebased source (`integrated-validation-r2.stdout`, sampled peak 240,062,464 bytes); `integrated-source-sha256-r2.txt` pins the updated readset. The pre-commit hook is rerun on the complete rebased staged diff.
